# Работа с реляционными базами данных SQLite на Python

## О проекте

Данный проект разработан в рамках производственной практики (научно-исследовательской работы). Основная цель — освоение принципов работы с реляционными базами данных с использованием встроенной библиотеки `sqlite3` языка Python.

В ходе работы созданы два консольных приложения:
- Интерактивная система для управления учебной базой данных (CRUD-операции)
- Аналитическая система для анализа статистики российских вузов

---

## Функциональные возможности

### 1. Управление учебной таблицей `educational_information`

| Функция | Описание |
|---------|----------|
| Просмотр структуры | Вывод списка полей таблицы с типами данных |
| Вывод всех записей | Отображение содержимого таблицы |
| Сохранение в файл | Экспорт данных в текстовый файл |
| Фильтрация | Выборка строк по условию (любое поле) |
| Добавление | Вставка новой записи через форму ввода |
| Обновление | Изменение значений в выбранных записях |
| Удаление | Удаление записей по условию |

### 2. Анализ данных о вузах (БД `VUZ.sqlite`)

#### Задача 1 — Фильтрация по проценту преподавателей с учёными степенями
- Расчёт процента = (кандидаты + доктора) / общий ППС × 100%
- Отображение минимального и максимального значения в выборке
- Вывод списка вузов, удовлетворяющих пороговому значению

#### Задача 2 — Распределение ведущих вузов по федеральным округам
- Выбор категории: только ФУ, только НИУ, или оба типа
- Формирование таблицы: округ → количество вузов → процент от общего числа
- Итоговая строка со значениями «Все» и 100%

### 3. Общие возможности
- Просмотр всех таблиц в базе данных
- Вывод структуры и содержимого любой таблицы (с возможностью ограничить количество строк)
- Обработка ошибок (несуществующий файл, таблица, некорректный ввод)

## Структура базы данных `VUZ.sqlite`

### Таблица `vuzkart` (карточка вуза)

| Поле | Тип | Описание |
|------|-----|----------|
| Codvuz | char(6) | Код вуза (первичный ключ) |
| z1full | char(250) | Полное юридическое наименование |
| region | char(17) | Федеральный округ |
| gr_ved | char(3) | ФУ / НИУ / нет |
| city | char(20) | Город |
| status | char(15) | Университет / академия / институт |

### Таблица `vuzstat` (статистика вуза)

| Поле | Тип | Описание |
|------|-----|----------|
| codvuz | char(6) | Код вуза (внешний ключ) |
| PPS | integer | Численность ППС |
| DN | integer | Доктора наук |
| KN | integer | Кандидаты наук |
